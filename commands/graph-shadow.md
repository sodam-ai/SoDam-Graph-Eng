거친 판정(`coarse`)인 형제를 **사람이 알려준 정보로** 채웁니다.

## 1단계 — 어디가 필요한지 보기

```
node "${CLAUDE_PLUGIN_ROOT}/lib/shadow.mjs"
```

출력에 **"먼저 이 N곳만 권합니다"** 가 나옵니다.

🔴 **여기 나온 곳만 물어보세요.** 6곳을 한꺼번에 물으면 12개 질문이 되고, 그러면 사용자가 답을 안 하게 됩니다. 그건 이 도구가 없애려는 **"사람 대기 → 정체"** 를 그대로 다시 만드는 것입니다.

## 2단계 — 두 가지만 묻기

권장된 형제마다 **딱 두 가지**만 물어보세요. 그 이상 묻지 마세요.

```
[진행 기록 정리]  {형제 이름}
  1. 마지막으로 끝낸 게 무엇인가요?
  2. 다음에 할 일은 무엇인가요?

  (건너뛰셔도 됩니다 — 지금처럼 "거친 판정"으로 계속 표시될 뿐입니다)
```

## 3단계 — 답을 받으면 기록

```
node "${CLAUDE_PLUGIN_ROOT}/lib/shadow.mjs" {형제 이름} --last "받은 1번 답" --next "받은 2번 답"
```

기록되면 **다음 스캔부터** 그 형제는 거친 판정에서 벗어납니다.

## 🔴 반드시 지킬 것

- **사용자가 말한 것만 적으세요.** 그럴듯하게 다듬거나, 빠진 부분을 추측해서 채우면 안 됩니다. 이 파일은 *"사람이 준 정보"* 라는 것이 존재 이유입니다.
- **사용자가 답을 안 해도 그냥 넘어가세요.** 재촉하지 마세요. 답이 없어도 이 프로젝트는 완료될 수 있습니다.
- **형제 저장소에는 아무것도 쓰지 않습니다.** 기록은 전부 이 도구 폴더 안(`data/shadow/`)에 저장됩니다. 사용자가 걱정하면 그렇게 알려주세요.
- 나중에 형제 쪽에서 진행 단계를 직접 읽을 수 있게 되면 **그쪽이 우선**이고 이 기록은 뒤로 물러납니다.
- 형제 이름을 **줄여 쓰지 마세요** — "루프" ❌ / "소담루프엔지니어링" ✅.

## 이미 적어둔 게 낡았다고 나오면

`/graph-next` 에 **"형제 쪽 기록이 그 뒤에 바뀌었습니다"** 가 뜨면, 그 형제만 2단계를 다시 하시면 됩니다.
