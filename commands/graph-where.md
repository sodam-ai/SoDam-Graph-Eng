소담 7형제 중 하나의 **실제 저장소 위치**를 찾아 알려주세요.

## 하는 일

사용자가 준 이름(`$ARGUMENTS`)으로 아래를 실행합니다.

```
node "${CLAUDE_PLUGIN_ROOT}/lib/resolve.mjs" $ARGUMENTS
```

- **이름을 안 줬으면** 인자 없이 실행해서 **7형제 전체 목록**을 보여주세요.
- 이름은 **한글 정식 명칭·영문 명칭·폴더명·저장소 이름 아무거나** 됩니다
  (예: `소담루프엔지니어링` · `SoDam-Loop-Eng` · `sodamloop` · `26y_06m_27d_SoDam-Loop-Eng`).

## 결과를 이렇게 전해 주세요

명령이 내놓은 값을 **그대로** 전하고, 어려운 말은 풀어 씁니다.

- **찾았을 때**: 저장소 루트 경로를 먼저, 그다음 역할 한 줄.
  - 🔴 **`저장소 루트`와 `폴더`가 다르면 반드시 둘 다 알려주세요.**
    소담루프엔지니어링은 저장소가 **폴더 한 겹 안쪽(`sodamloop/`)** 에 있습니다.
    이걸 안 알려주면 사용자가 바깥 폴더에서 작업하다 헤맵니다 — 이 도구가 만들어진 이유가 그것입니다.
- **`경로 유실`(lost)이 나왔을 때**: **옛 경로를 추측해서 알려주지 마세요.**
  "지금은 못 찾았습니다"라고 정직하게 말하고, `data/graph.json` 의 `config.search_roots` 를 확인하라고 안내하세요.
- **`경로 거부`(rejected_path)가 나왔을 때**: `graph.json` 의 `markers` 가 안전하지 않은 경로입니다. 파일을 읽지 않고 막은 것이니 **정상 동작**이라고 알려주세요.
- **후보가 여러 개**로 나왔을 때: 목록을 그대로 보여주고 **하나를 정확히 다시 말해 달라고** 요청하세요. 임의로 고르지 마세요.
- 출력 끝의 `[HH:MM 기준]` 은 **언제 찾은 값인지**를 뜻합니다. 여러 창을 켜고 작업하면 값이 바뀔 수 있어서 붙습니다 — 그대로 함께 보여주세요.

## 규칙 (이 명령의 안전 범위)

- 이 명령은 **읽기만 합니다.** 형제 프로젝트의 파일을 **고치거나 만들지 않습니다.**
- 찾은 경로로 **자동으로 이동하거나 다른 작업을 시작하지 마세요.** 알려주는 데서 멈춥니다.
- 경로를 **추측해서 지어내지 마세요.** 명령이 못 찾았으면 못 찾은 것입니다.
- 형제 이름을 **줄여 쓰지 마세요** — "루프" ❌ / "소담루프엔지니어링" ✅.
