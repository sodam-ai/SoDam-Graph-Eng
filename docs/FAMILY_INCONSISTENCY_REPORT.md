## 불일치 ④ GitHub이 인식하는 라이선스가 형제마다 다릅니다

로컬 `LICENSE`는 6/6 전부 Apache-2.0인데, GitHub 인식은 갈립니다:

| 인식 | 형제 | 로컬 LICENSE 줄 수 |
|------|------|------------------|
| `apache-2.0` ✅ | 하네스·프롬프트·리버스 | 201줄 (표준 전문) |
| `other` ❌ | 컨텍스트·에이전틱·루프 | 179·198·190줄 (전문이 짧음) |

가능성(단정 아님): 인식되는 쪽은 전부 201줄 표준 전문이고, `other`인 쪽은 전문이 잘려 있거나 변형됐습니다. 소담그래프엔지니어링은 201줄 표준 전문을 그대로 넣어 M0에서 `apache-2.0` 인식을 확인했습니다(커밋 `a02f7cf`).

## 불일치 ⑥ 마켓플레이스 이름 형식이 4갈래입니다

정본 §5는 "형제마다 고유 이름"만 규정하고 형식은 규정하지 않았습니다:

| 형식 | 형제 |
|------|------|

| 플러그인 이름과 동일 | 에이전틱 |
| `{x}-marketplace` (하이픈) | 프롬프트 |
| `{x}-local` | 루프 |

GitHub 마켓플레이스 통일 표준(2026-08-02 확정)이 있는 이상, 이 형식 불일치가 사용자 편의에 직접 영향을 줍니다. 소담그래프엔지니어링은 다수파(`sodamgraph-marketplace`)를 따랐습니다.
