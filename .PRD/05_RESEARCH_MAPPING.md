## 4. 조사 자료가 던지는 근본 질문 — 우리의 답

자료 §1 결론은 Graph Engineering을 **5축**으로 정의합니다. 우리는 그중 어디에 있는가:

| 축 | 우리 위치 |
|---|----------|
| ① **Task Graph / Agent Graph** | **여기가 우리 자리.** 7형제 = 노드, 의존 = 엣지, 마일스톤 = 상태 |
| ② Knowledge Graph / Memory Graph | ❌ O-Brain · SoDam-WikiMate 담당 |
| ③ Code Graph | 🕐 Phase 3 |
| ④ GraphRAG / Context Graph | ❌ 소담컨텍스트엔지니어링 담당 |
| ⑤ Graph Runtime / Observability | 🕐 Phase 2.5 이후 |

> **이 표가 형제 간 중복을 막는 최종 방어선입니다.** 소담그래프엔지니어링은 ①번 축만 합니다.
> ②④를 건드리기 시작하면 O-Brain·소담컨텍스트엔지니어링과 정면 충돌합니다.
