## 4. 사용자 흐름

### 핵심 흐름

```
세션 시작 → graph.json 읽기 → 형제·경로 확정 → 단계 판정 → 다음 할 일 1개 지목 → (실행은 사람 또는 소담루프엔지니어링)
```

### 상세 흐름

1. **읽기**: `graph.json` 을 로드한다 (설치·서버 없음, 그냥 파일)
2. **🔴 찾기 (resolve)**: 형제가 **지금 어디 있는지** 알아낸다 — `repo_remote`(정규화 비교) → `markers` → 못 찾으면 `lost`
   - **경로를 정본에 저장하지 않으므로 매번 다시 찾습니다.** 폴더를 개명해도 안 깨지는 이유가 이 단계입니다
3. **실측**: 찾아낸 `repo_root` 기준으로 읽기 전용 스캔 — git 마지막 커밋, 미커밋 수, 추적 파일, 1층 추출
4. **대조**: `graph.json` 에 적힌 상태와 실측값이 어긋나면 **어긋났다고 표시한다** (조용히 덮어쓰지 않음)
5. **판정**: 각 형제의 현재 노드와 다음 노드를 결정한다 + `done` 승격 후보 판정
6. **지목**: 다음 할 일 1개 + 사람 몫 블로커를 출력한다 (**스캔 시각 함께 표시**)
7. **발행**: `~/.sodam/graph-state.json` 에 요약을 원자적으로 쓴다 → **6형제가 읽어감**
8. **정지**: 여기서 멈춘다 — **밀어붙이는 실행은 소담그래프엔지니어링의 일이 아니다**
