## 해결하려는 문제 3가지

| # | 문제 | Phase 1에서 |
|---|------|-----------|
| ① | 형제마다 폴더 구조가 달라 AI가 경로를 헷갈림 | **설계됨** — `repo_remote` 로 찾고 폴더 개명에도 안 깨짐 |
| ② | 세션 바꾸면 진행 상황을 처음부터 다시 설명 | **설계됨** — 세션 시작 자동 주입 (3줄, 1초) |
| ③ | 검증 끝났는데 다음 단계로 안 넘어감 | **설계됨** — `done` 자동 승격 + `/graph-why` + 그림자 ([06번](./06_ANTI_STALL_SPEC.md)) |

> 🔴 **"해결"이 아니라 "설계됨"입니다.** 코드가 아직 0줄이므로 해결 여부는 [`01_PRD.md §5`](./01_PRD.md) 의 **2주 후 측정 3항목**으로만 판정합니다.
